# 🌊 亿中选一 (Krillion Multiplayer · 中文多人版)

> 越冷门，下潜越深！基于流行每日猜词游戏 [Krillion](https://playdaily.org/krillion) 打造的多人实时联机网页版。

---

## 🌐 如何让不同网络的好友一起联机？ (Connect with Different Internet)

为了让你和不在同一个 WiFi 下的朋友（比如不同住处、用手机 4G/5G 流量、不同城市）都能随时一起玩，我们提供了两种非常简单的方法：

---

### 方案 A：一键外网穿透（无需注册，双击即用）🌟 推荐

在游戏文件夹内，我们已经为你编写好了专用的公网穿透脚本：

1. **直接双击运行：**  
   👉 `share-to-internet.bat` （使用 Windows 系统内置安全加密通道，**零下载、零安装**）  
   或  
   👉 `cloudflare-tunnel.bat` （使用 Cloudflare 全球高速加速网络）

2. **获取专属公网网址：**  
   黑框中会自动输出一个公网 HTTPS 链接，例如：  
   `https://xxxxx.lhr.life` 或 `https://xxxxx.trycloudflare.com`

3. **发给好友：**  
   把这个链接发给微信/QQ群里的好友。好友无论用手机流量还是家里的 WiFi，点开链接就能进入游戏并输入房间码！

---

### 方案 B：免费部署到云端（24小时永久在线，不用一直开着电脑）

如果你想获得一个固定的永久网址（例如 `https://krillion.onrender.com`），可以免费托管到各大云平台：

#### 推荐平台 1：[Render.com](https://render.com)（完全免费）
1. 注册并登录 Render.com，点击 **New +** ➔ **Web Service**。
2. 上传当前文件夹或关联你的 GitHub 仓库。
3. 参数设置：
   - **Environment:** `Node`
   - **Build Command:** 留空
   - **Start Command:** `node server.js`
4. 点击 **Create Web Service**，1分钟后就会分配一个永久在线的 `https://xxxx.onrender.com` 网址！

#### 推荐平台 2：[Glitch.com](https://glitch.com)
1. 打开 Glitch.com，点击 **New Project** ➔ **Import**。
2. 将代码放入，Glitch 会即时分配公网链接。

---

### 方案 C：同局域网 / 宿舍 WiFi 快速对战

如果是宿舍或同一个 WiFi 下的好友：
1. 双击运行 `start-game.bat`。
2. 控制台会显示你的局域网 IP（例如 `http://10.20.188.37:3000`）。
3. 连入同 WiFi 的好友直接打开该地址即可开始。

## ✨ 核心游戏玩法与设置

1. **👥 房间系统（最多 10 人）**
   - 房主点击「创建新房间」，自动生成 **5 位专属大写邀请码**（如 `598MV`）。
   - 好友在首页的「加入好友房间」输入框填入邀请码，或点击邀请链接一键加入。

2. **⚙️ 大厅自定义设置（房主可调，全员实时同步）**
   - **题目数量：** 可选 3 题、5 题、7 题（经典）、10 题、12 题（3 ~ 15 题）。
   - **作答时间：** 可选 15 秒（极速）、20 秒、25 秒（经典）、35 秒、45 秒（10 ~ 60 秒）。

3. **🍎 轻松生活化题库（拒绝生僻八股文）**
   - 包含日常水果、常见动物、日常蔬菜、世界国家、体育运动、日常饮品、汽车品牌、音乐乐器、职业工作、美丽花朵、海洋生物、中外节日、甜品小吃、数码电子、桌游棋牌、热门游戏（王者/LOL/原神/黑神话等）、常用手机App等 30+ 类生活话题！

4. **🎯 稀有度与深潜机制**
   - 🦐 **浮游 (Plankton)**：+10 分（下潜 100米）— 最容易想到的常见答案
   - 🐠 **聪明 (Clever)**：+15 分（下潜 150米）
   - 🐟 **鱼群 (Schooler)**：+30 分（下潜 300米）
   - 🐡 **稀有 (Rare)**：+60 分（下潜 600米）
   - 🦑 **深海 (Deep Cut)**：+85 分（下潜 850米）
   - 🐙 **亿中选一 (Krillion)**：+100 分（下潜 1,000米）— 极致冷门宝藏正解！

5. **🏆 单轮排名与终局盛典**
   - 错答不扣分，只消耗倒计时，时间结束前可无限次重试。
   - 命中有效答案立即锁定，全员交卷后即时公布所有人提交的词汇与排名。
